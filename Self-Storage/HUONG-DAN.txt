THANH TOÁN TIỀN CỌC QUA VNPAY SANDBOX

1) Lấy khóa sandbox: đăng ký tại https://sandbox.vnpayment.vn/devreg/
   VNPay gửi qua email: vnp_TmnCode và vnp_HashSecret.

2) Thêm vào backend/appsettings.Development.json (KHÔNG commit HashSecret lên GitHub):
   "VnPay": {
     "TmnCode": "<vnp_TmnCode>",
     "HashSecret": "<vnp_HashSecret>",
     "BaseUrl": "https://sandbox.vnpayment.vn/paymentv2/vpcpay.html",
     "ReturnUrl": "http://localhost:8080/payment-result"
   }
   (ReturnUrl đổi theo cổng frontend đang chạy: 5173 hoặc 8080.)

3) Chép đè các file trong zip, dừng backend rồi dotnet run lại.
   File backend MỚI (chỉ thêm): backend/Controllers/VnPayController.cs

4) Thẻ test (ngân hàng NCB):
   Số thẻ 9704198526191432198 · Tên NGUYEN VAN A · Ngày phát hành 07/15 · OTP 123456

5) (Không bắt buộc) IPN: VNPay chỉ gọi được URL public. Khi demo có ngrok / Dev Tunnels,
   khai báo IPN URL trong trang quản trị sandbox: https://<tunnel>/api/vnpay/ipn
   Không có IPN vẫn chạy: trang /payment-result tự gửi kết quả về backend để kiểm tra chữ ký.

6) Demo không có mạng: thêm VITE_ALLOW_SIMULATED_PAYMENT=true vào frontend/.env
   -> có thêm lựa chọn "Mô phỏng" như trước.
